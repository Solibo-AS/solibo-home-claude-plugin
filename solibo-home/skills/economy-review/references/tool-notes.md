# Tool notes for economy review

Ids are strings except in the three accounting tools, where `companyId`, `companyIds` and `projectId` are
integers. Dates are ISO dates (YYYY-MM-DD); timestamps need an offset.

| Tool | Required | Useful optional arguments | Result fields to use |
|---|---|---|---|
| `get_economy_readiness` | `companyId` | none | `accountingAvailable`, `invoicingActive`, `unattestedExpenseCount`, `unattestedSupplierInvoiceCount`, `unattestedSupplierInvoiceCountUnverified` |
| `get_company_economy_overview` | `companyId` | none | `economyStatus`, `loans[].{id,supplierName,loanType,remainingSum}`, `insurances[].{id,supplierName,premium}`, `economicReports[].{id,status,orderedAt,forPeriod,reportDocumentId}`, `unpaidInvoices[].{tripletexId,supplierName,amount,currency,dueDate,status,statusCode,remainder}` (`statusCode` is the API value such as FOR_APPROVAL), `sources.*` (`reason` says why a source is not complete). `insurances[]` holds only policies without an end date |
| `get_economy_status` | `companyId` | none | `availableFunds`, `availability`, `currency`, `source`, `dataNotice`, `bankAccounts[].{name,bank,balance,latestStatement}`, `loanAccounts[]` (`ledgerAccountId`: a ledger account, not a loan id) |
| `get_accounting_overview` | `companyId` (int), `periodStart`, `periodEnd` | none | `company.{dataAsOf,coverageFrom,coverageTo,complete,dataStatus,dataStatusNote,budgetAvailable,budgetStatus}` (`dataStatusNote` only for NOT_SYNCED), `totals[].{currency,actualIncome,actualExpenses,actualNet,budgetIncome,budgetExpenses,budgetNet,expenseVariance,netVariance}`, `dimensions[].{dimension,id,name,totals,budgetAvailable}`, `liquidity[]` |
| `search_accounting_entries` | `periodStart`, `periodEnd`, `companyId` (int) or `companyIds` (ints, max 500) | `accountNumbers`, `projectIds`, `departmentIds`, `supplierIds`, `search`, `count` (100), `pageToken` | `items[].{companyId,id,postingDate,accountNumber,accountName,amount,currency,voucherId,projectName,departmentName,supplierName}`, `paging.next`, `meta.totalCount` |
| `get_accounting_project` | `companyId` (int), `projectId` (int), `periodStart`, `periodEnd` | none | `projectName`, `totals[]` |
| `search_expenses` | none | `companyIds`, `search`, `status` [FOR_APPROVAL, APPROVED, REJECTED], `dateOfPurchaseFrom`, `dateOfPurchaseTo`, `count` (20), `pageToken` | `items[].{id,companyId,companyScopeResolved,account (masked, last four),accountMasked,amount,expenseType,dateOfPurchase,description,status,payableToName}`, `paging.next` |
| `get_expense` | `companyId`, `expenseId` | none | `account` (masked, last four), `amount`, `expenseType`, `expenseTypeId`, `status`, `statusCode`, `approvalsRequired` (2), `approvalsGiven`, `rejectionReason`, `receiptDocumentIds[]`, `expenseProcessing[]` and `processingHistory[].{result,performedAt,performedById,performedByName,rejectionReason}` |
| `accept_expense` | `companyId`, `expenseId` | `title` | preview, then `confirm_pending_write`; result `statusCode`, `approvalsGiven`, `fullyApproved` (one approval of two leaves it for approval) |
| `reject_expense` | `companyId`, `expenseId` | `reason` | preview, then `confirm_pending_write`; result `statusCode`, `rejectionReason` |
| `create_expense` | `companyId`, `account`, `amount`, `dateOfPurchase`, `expenseTypeId` (from `list_expense_types`), `payableTo` (person id from `search_persons` or `lookup_person`) | `description`, `files`, `attachments` | after confirmation claim fields, `expenseCreated`, `attachmentsComplete`, `documentIds`, `attachmentResults[].{index,status,documentId}`, `attachmentRecovery` |
| `get_document_upload_options` | `companyId` | `documentType` EXPENSE, `belongsToId` existing expense ID | `homeUrl`, `uploadInstruction`, `reuseInstruction`, `fileTransferGuidance` (read-only; manual upload) |
| `browse_document_folder` | `companyId`, `documentType` EXPENSE | `belongsToId` existing expense ID, `count`, `pageToken` | `items[].{id,sourceDocumentId,belongsToId,fileName}`, `paging.next` |
| `upload_document` | `companyId`, `documentType` EXPENSE, exactly one `file` or `sourceDocumentId` | `belongsToId` existing expense ID; `fileName`, `parentId` only for new file | preview, then `confirm_pending_write`; `documentId` |
| `get_invoices` | `companyId` | `archive`, `year` | `invoices[].{id,tripletexId,supplierName,supplierOrgNr,description,amount,currency,invoiceDate,dueDate,status,outstanding,remainder,invoiceProcessing[]}` (unpaged) |
| `get_company_supplier_invoice_approval_status` | `companyId` | none | `forApprovalCount`, `forApprovalInvoiceIds[]`, `unattestedCount`, `invoices[].{tripletexId,supplierName,amount,currency,dueDate,invoiceProcessing[].{result,performedAt,performedByName}}`, `invoicesTruncated`, `invoiceRowsUnavailable` |
| `approve_supplier_invoice` | `companyId`, `invoiceId` (the `tripletexId`) | `reason` | preview, then `confirm_pending_write` |
| `reject_supplier_invoice` | `companyId`, `invoiceId` (the `tripletexId`) | `reason`, `description` | preview, then `confirm_pending_write` |
| `get_unapproved_invoices_overview` | none | `companyId`, `companyIds` | `companies[].{companyId,companyName,invoiceCount,earliestDueDate,invoices[]}`, `totalInvoices`, `unverifiedCompanyIds` |
| `get_supplier_invoice_approval_counts` | none | none | `counts[].{companyId,count}`, `totalCount` (cached; an empty list carries a `note` and does not mean nothing awaits approval) |
| `get_company_invoice_history` | `companyId`, `periodStart`, `periodEnd` | `open`, `payerType`, `search`, `count` (100), `pageToken` | `items[].{id,number,description,dueDate,invoiceDate,sum,open,type,sectionId,payerName,payerType,reminderStage,delivery}`, `paging.next` |
| `get_invoice_history_for_companies` | `periodStart`, `periodEnd` | `companyIds`, `search` (max 25 companies), `payerType`, `open`, `count`, `pageToken` | same item fields plus `companyId`, `paging.next` |
| `get_invoice_payments` | `companyId`, `invoiceId` | `count`, `pageToken` | `items[].{id,amount,currency,paymentDate,payerName,paymentHandling}` |
| `get_customer_invoices` | `companyId`, `customerType` (PERSON, ORGANIZATION), `customerId` (both from a `search_invoicing_customers` row, which takes `search`) | `count`, `pageToken` | `items[].{id,number,dueDate,sum,open,reminderStage,outstanding{total}}`; no `outstanding` means unknown |
| `get_loans` | none | `companyId`, `loanId`, `companyIds`, `search` (supplier, loan number or loan type such as Serielån), `active`, date bounds, `count`, `pageToken` | `items[].{id,supplierName,loanNumberMasked,loanType,initialSum,remainingSum,interest,startDate,endDate,inAgreement,ledgerAccountLinked}`; `interest` is the rate in effect today (also on a single `loanId` read); `remainingSum` only when `ledgerAccountLinked` is true |
| `get_insurances` | none | `companyId`, `insuranceId`, `companyIds`, `search`, `count`, `pageToken` | `items[].{id,supplierName,policyNumber,premium,startDate,endDate}` (masked; `endDate` is an Oslo calendar date) |
| `get_economic_reports` | none | `companyId`, `reportId`, `companyIds`, `forPeriod` (month 1-12), `year` (the year the report was ordered in), `status` (ORDERED, DELIVERED) | `items[]` (across companies paged; one company complete, also as `reports[]`), rows `{id,companyId,status,orderedAt,forPeriod,reportDocumentId,departmentDocumentId,projectDocumentId}` |
| `reveal_loan_numbers`, `reveal_insurance_policy_numbers` | as the masked tool | `count` (5) | full numbers; audited, explicit permission only |
| `reveal_expense_account_numbers` | `companyId` | `expenseIds` (at most 20), `count` (5) | `items[].{expenseId,account,amount,payableToName,status}` with the full payout account, `notFoundExpenseIds`; audited, explicit permission only |
| `confirm_pending_write` | `previewId`, `confirmed` (true) | none | `pendingAction.{status,executed,dryRun,message}`, `result` |
