# Solibo Home plugin

The Solibo Home plugin for Claude lives in [`solibo-home/`](solibo-home/): its
manifest, skills, README, changelog and licence. Install it from the Claude
directory once it is listed; see [`solibo-home/README.md`](solibo-home/README.md).

This repository is published from the Solibo Home MCP service repository; changes
arrive as release pull requests.
